# Can an AI Recognize Another AI?

### From Machine-Text Detection to Model Attribution

This repository contains the code, data, and experiments for our final NLP course project.

The project investigates two related questions:

1. **AI-generated text detection:** Can we reliably distinguish human-written text from LLM-generated text?
2. **Model attribution:** If a text was generated by an LLM, can we identify which model produced it?

We compare several approaches, including detection methods, supervised classifiers, perplexity-based attribution, human evaluation, and LLMs used as judges.

## Project Overview

We constructed a controlled multi-domain corpus containing **human-written texts and texts generated by several LLMs**.

The experiments cover five domains:

* News
* Opinion
* Reviews
* Stories
* How-to / explanatory texts

The machine-generated texts were produced using several open-weight language models, including:

* Mistral-7B-Instruct
* Qwen3-4B-Instruct
* SmolLM3-3B
* Phi-4-mini-instruct
* Gemma

Human texts were selected from domain-appropriate datasets and processed to make the comparison between human and generated texts as controlled as possible.

### `Partie0_Data`

Contains the code and files related to **dataset construction and preprocessing**.

---

### `Partie1_Detection`

Contains the experiments related to **human vs. AI text detection**.

In particular, we evaluate **Binoculars**, a zero-shot AI-generated text detection method, and analyze its behavior across models and text domains.

An important observation from the project is that detection performance varies substantially depending on the generating model: some models are detected almost systematically, while others produce texts that are much harder for the detector to distinguish from human writing.

---

### `Partie2_Classifier`

Contains our **supervised classification experiments**.

We train classifiers using features extracted from the texts and evaluate whether a learned classifier can distinguish:

* Human vs. AI-written texts
* Texts generated by different models

The supervised classifier obtained the strongest attribution performance among the approaches evaluated in the main experiments.

---

### `Partie3_Juge`

Contains experiments in which an **LLM is used as a judge**.

Instead of relying on an explicit statistical detector, the language model receives a text and is asked to determine its likely authorship.

We use these experiments to study whether LLMs themselves are able to recognize the characteristic outputs of other language models.

---

### `Partie3_LLMasAJudge`

Contains additional **LLM-as-a-Judge experiments**, including experiments with external/API-based models such as **Gemini and GPT**.

These experiments complement the smaller local LLM judge by testing whether more capable proprietary models perform better at distinguishing human and AI-generated writing.

---

### `Partie3_LLMJudge_nosTextes`

Contains additional experiments performed on a **small custom set of human and AI texts** designed to further test the behavior of LLM judges.

These experiments were particularly useful for examining cases where texts may contain misleading stylistic characteristics and therefore be harder to classify purely from writing style.

## Methods Compared

The project compares several different ways of recognizing authorship:

| Method                       | Main Task                        |
| ---------------------------- | -------------------------------- |
| Human evaluators             | Human vs. AI                     |
| Binoculars                   | Human vs. AI                     |
| LLM as a judge               | Human vs. AI / model attribution |
| Perplexity-based attribution | Identify generating model        |
| Supervised classifier        | Human / generating model         |

This allows us to compare approaches based on very different assumptions: human intuition, zero-shot detection, generative-model reasoning, language-model likelihoods, and supervised learning.

---

## Selected Results

Some of the main results obtained in our experiments were:

| Recognizer                     | Task                      |  Accuracy |
| ------------------------------ | ------------------------- | --------: |
| Humans (`n=21`)                | Human vs. AI              | **59.5%** |
| Binoculars                     | Human vs. AI              | **68.8%** |
| LLM judge (Qwen2.5-1.5B)       | Model attribution         | **20.0%** |
| Perplexity argmin              | Model attribution         | **77.6%** |
| Logistic Regression classifier | Model / human attribution | **92.0%** |

The experiments highlight an important distinction between **AI-text detection** and **model attribution**.

While simply asking an LLM to identify the author performed poorly, likelihood-based attribution and especially supervised classification were considerably more successful.

We also observed that AI-text detection is **highly dependent on the generating model and domain**, meaning that a detector performing well on one model does not necessarily generalize to another.

## Main Takeaway

Our results suggest that answering *“Was this written by AI?”* and *“Which AI wrote this?”* are substantially different problems.

Generic AI-text detection does not behave consistently across generating models, and directly asking another LLM to recognize the author is not necessarily effective. In contrast, model-specific likelihood information and supervised classifiers can contain strong attribution signals.

This raises an interesting conclusion: **LLMs may leave identifiable statistical fingerprints in their outputs even when those fingerprints are difficult for humans—or other LLMs—to recognize directly.**
